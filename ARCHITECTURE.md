# GRA–Heisenberg Reasoning Architecture  
## Two-Loop Degeneracy-Aware AI System

---

## ENGLISH

### Overview

This repository describes a **two-loop reasoning architecture**
designed to stabilize AI cognition under conditions of solution degeneracy.

The architecture combines:
- Generalized Resonance Algorithm (GRA)
- Orthogonal auxiliary constraints
- Minimum uncertainty (Heisenberg-style) bounds
- Large Language Models (LLMs) as hypothesis generators

This is **not a chatbot**.  
This is a **meta-cognitive reasoning architecture**.

---

### Two-Loop Structure

#### Inner Loop (Reasoning Loop)
- Generates candidate solutions or hypotheses
- Evaluates them with respect to a primary objective
- Detects degeneracy (multiple equivalent minima)

#### Outer Loop (Meta Loop)
- Monitors instability caused by degeneracy
- Introduces orthogonal auxiliary constraints
- Controls collapse strength within uncertainty bounds

---

### Role of the LLM

The LLM does **not** select the final answer.

It is used as:
- A structured hypothesis generator
- A semantic exploration engine
- A source of diverse candidate states

Stability is achieved by the GRA-based mechanism,
not by token probability maximization.

---

### Degeneracy Collapse

When multiple solutions are equivalent with respect to the main goal,
the system becomes unstable.

Orthogonal constraints collapse this degeneracy
without modifying the original objective function.

The result is a **single stable cognitive state**.

---

### Key Principle

> Stability is achieved not by optimization,
> but by controlled symmetry breaking.

## РУССКИЙ

### Обзор

В репозитории описывается **двухконтурная архитектура рассуждения**,
предназначенная для стабилизации ИИ в условиях дегенерации решений.

Архитектура объединяет:
- Обобщённый резонансный алгоритм (GRA)
- Ортогональные вспомогательные ограничения
- Принцип минимальной неопределённости (по аналогии с Гейзенбергом)
- Большие языковые модели (LLM) как генераторы гипотез

Это **не чат-бот**.  
Это **метакогнитивная архитектура рассуждения**.

---

### Двухконтурная структура

#### Внутренний контур (контур рассуждения)
- Генерирует возможные решения или гипотезы
- Оценивает их по основной целевой функции
- Обнаруживает дегенерацию (равнозначные минимумы)

#### Внешний контур (метаконтур)
- Отслеживает нестабильность из-за дегенерации
- Вводит ортогональные ограничения
- Контролирует силу коллапса с учётом неопределённости

---

### Роль LLM

LLM **не выбирает финальный ответ**.

Она используется как:
- Генератор структурированных гипотез
- Инструмент семантического поиска
- Источник разнообразных состояний

Финальная стабилизация выполняется механизмом GRA,
а не вероятностным выбором токенов.

---

### Коллапс дегенерации

Когда несколько решений эквивалентны по основной цели,
система становится нестабильной.

Ортогональные ограничения устраняют дегенерацию,
не изменяя исходную цель.

Результат — **одно устойчивое когнитивное состояние**.

---

### Ключевой принцип

> Устойчивость достигается не оптимизацией,
> а контролируемым нарушением симметрии.
